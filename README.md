# WerkRekenen.com 🇳🇱

**WerkRekenen.com** is a Netherlands-focused website providing simple, fast and easy-to-use calculators for work, salary, working hours, travel expenses and other work-related calculations.

The platform is built specifically for people in the **Netherlands** and provides its tools and information in **Dutch (Nederlands)**.

🌐 **Website:** https://werkrekenen.com/

---

## 🎯 About WerkRekenen.com

WerkRekenen.com helps people quickly answer everyday questions related to work and income without complicated calculations.

The platform focuses on practical questions such as:

* What is my hourly wage?
* How much are my travel expenses?
* How much overtime pay should I calculate?
* How much holiday allowance do I receive?
* How many working days are there?
* How much can I calculate for working from home?
* How does my salary change when I work part-time?

The goal is to provide **clear, accurate and easy-to-use calculation tools** designed around the Dutch market.

## 🚀 Performance & SEO

Performance and search engine optimization are core priorities of WerkRekenen.com.

The website is designed with a lightweight, static-first architecture to provide a fast experience across mobile and desktop devices.

The project focuses on:

* Core Web Vitals
* Fast page loading
* Minimal JavaScript
* Optimized assets
* Semantic HTML
* Clean URL structures
* Canonical URLs
* XML sitemap
* Robots.txt
* Structured data where appropriate
* Internal linking
* Dutch-language SEO
* Search-intent-focused calculator pages

The goal is to make every calculator useful for both users and search engines without relying on unnecessary scripts or heavy UI frameworks.

## 📁 Project Structure

The project uses a reusable architecture so new calculators can be added without rebuilding the entire website.

Typical areas include:

```text
src/
├── components/
├── layouts/
├── pages/
├── styles/
└── ...
```

Reusable components are used for common elements such as:

* Header
* Footer
* Calculator layouts
* Calculator inputs
* Results
* FAQs
* Breadcrumbs
* Related calculators
* SEO metadata

This makes the platform easier to maintain and expand.

* Applicable year
* Assumptions
* Calculation method
* Relevant official sources
